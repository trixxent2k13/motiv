# AE Time Tracker

Таймтрекер для After Effects: автоматически отслеживает время работы над проектом и логирует сессии в текстовый файл рядом с .aep.

## Логика работы

- При открытии **сохранённого** проекта панель начинает отслеживание
- Кнопка **Пауза** — приостановить отслеживание (например, ожидание заказчика), **Продолжить** — возобновить
- При закрытии проекта или переключении на другой — записывает сессию в файл `{имя_проекта}.time.txt` рядом с .aep
- Файл содержит все сессии и итоговое суммарное время
- **Несохранённые проекты** (Untitled) не отслеживаются — нужен путь к .aep

### Рекомендация по закрытию

**Закрывайте проект перед выходом из AE** (File → Close Project или Ctrl+W), а не закрывайте After Effects целиком. Тогда сессия гарантированно записывается в файл. Если закрыть AE без закрытия проекта, запись может не успеть выполниться, но сработает восстановление (см. ниже).

### Бэкап и восстановление

Каждые 30 секунд панель сохраняет «снимок» текущей сессии в файл `%TEMP%\aett_pending.txt`. Это синхронная запись ExtendScript, она успевает выполниться даже при интенсивной работе.

**Если последняя сессия не записалась** (закрыли AE целиком, перезагрузка, сбой):

1. При следующем запуске After Effects панель при загрузке проверяет наличие `aett_pending.txt`
2. Если файл найден — сессия дописывается в `.time.txt`, после чего файл удаляется
3. Теряется максимум ~30 секунд (время с последнего бэкапа до закрытия)

Дубликаты сессий не добавляются: перед записью проверяется, есть ли в файле строка с тем же временем начала.

## Установка

### Автоматическая (Windows)

**Запустите install.bat от имени администратора** (ПКМ → «Запуск от имени администратора») или `install.ps1` с правами администратора. Скрипт:
- Включает режим отладки CEP в реестре
- Копирует расширение в `%AppData%\Adobe\CEP\extensions\`

### Ручная

1. Режим отладки CEP: добавьте в реестр `HKEY_CURRENT_USER\Software\Adobe\CSXS.11` (или CSXS.10 для AE 2022) параметр `PlayerDebugMode` = `1`
2. Скопируйте папку `AETimeTracker` в `%AppData%\Adobe\CEP\extensions\`
3. **macOS:** `defaults write com.adobe.CSXS.11 PlayerDebugMode 1` и копируйте в `~/Library/Application Support/Adobe/CEP/extensions/`

### После установки

Перезапустите After Effects → **Window → Extensions → AE Time Tracker**

## Формат лог-файла

```
=== AE Time Tracker ===
2025-03-10 09:15:22 — 10:42:08  |  1h 26m 46s
2025-03-10 14:00:00 — 16:30:15  |  2h 30m 15s

--- ИТОГО: 3h 57m 01s ---
```

## Режим отладки

Если панель не работает, **тройной клик** по статусу («Нет проекта» / «Отслеживание») открывает отладочную панель. Она показывает:
- наличие CSInterface;
- версию After Effects;
- результаты вызова ExtendScript;
- лог последних ответов.

Кнопка **Скопировать** копирует отчёт в буфер — можно отправить разработчику.

## Ограничения

- Панель должна быть **открыта** во время работы — иначе опрос (polling) не идёт
- Отслеживаются только **сохранённые** проекты
- Интервал опроса: 1 секунда (при торможениях можно увеличить в main.js)

## Технологии

- CEP (Common Extensibility Platform) + ExtendScript
- Polling: нет нативных событий открытия/закрытия проекта в AE API
