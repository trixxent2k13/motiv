# Smart Sync Assets (CEP)

CEP-версия скрипта синхронизации исходников. **v1.0.005** Копирует внешние файлы в `[Имя_проекта]_Assets` рядом с проектом и перепривязывает их в After Effects.

**Отличие от .jsx версии:** панель CEP с проверкой обновлений. При появлении новой версии в [Releases](https://github.com/trixxent2k13/motiv/releases) показывается уведомление.

## Установка

**Запустите install.bat от имени администратора** или `install.ps1` с правами администратора.

После установки: **Window → Extensions → Smart Sync Assets**

Кнопка **Help** открывает [репозиторий проекта](https://github.com/trixxent2k13/motiv/tree/main/SmartSyncAssetsCEP).

## Использование

1. Сохраните проект (File → Save)
2. Нажмите **Sync**
3. Опция «Удалить дубликаты» — удаляет исходные файлы после копирования

## Поддерживается

- Одиночные файлы
- Секвенции кадров (подпапка `Seq_[Имя]`)
- Защита от перезаписи (`_1`, `_2` при совпадении имён)
