# motiv

Сборник публичных утилит и скриптов от моушен-дизайнера Ильи Васькина.

- [Smart Sync Assets](SmartSyncAssets/) — скрипт After Effects для синхронизации исходников в папку проекта
- [Smart Sync Assets CEP](SmartSyncAssetsCEP/) — CEP-версия с проверкой обновлений (экспериментально)
- [AE Time Tracker](AETimeTracker/) — CEP-панель After Effects: таймтрекер задач, логирование сессий рядом с .aep
- [Yandex Map Cleaner](yandex-map-cleaner/) — расширение Chrome/Edge: минималистичный UI на картах Яндекса, переключатель темы
