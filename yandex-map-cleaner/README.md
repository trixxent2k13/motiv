# Yandex Map Cleaner


**Проект в Archive** — разработка завершена.

Расширение для Chrome/Edge: скрытие интерфейса на Яндекс.Картах, переключение темы, копирование кода камеры.

## Если перестало работать после обновления карт

1. **Откройте** [yandex.ru/maps](https://yandex.ru/maps) и дождитесь полной загрузки карты.
2. **Нажмите** на иконку расширения → кнопку **«Диагностика»**.
3. **Посмотрите вывод:**
   - **Скрипты** — показывает какие скрипты карт загружаются (для справки).
   - **Селекторы** — ✓ и число = элементы найдены, ✗ 0 = классы/разметка на сайте изменились, нужно обновить селекторы в `content.js` и `popup.js`.
   - **force-theme подписан** — теперь не критично, т.к. переключение темы работает через DOM (класс `_theme_dark` на body).
   - **yandex_map: есть/нет** — нужен для кнопки «Copy camera code» (может отсутствовать в новых версиях карт).

4. **Переустановите расширение:** `chrome://extensions` → «Обновить» у Yandex Map Cleaner.

## Как работает переключение темы

С версии 1.1 переключение темы работает через **DOM-манипуляции** (добавление/удаление класса `_theme_dark` на `body`), а не через перехват скрипта карт. Это более надёжно и не зависит от внутренней структуры скриптов Яндекса.

## Структура

- `content.js` — автозакрытие сайдбара и скрытие элементов по флагу autoSwitch.
- `popup.js` + `popup.html` — кнопки Toggle UI, Toggle Theme, Copy camera code, Диагностика.
- `background.js` — перехват запроса скрипта карт и подмена на `scripts/custom-map-features.js` (в нём хук переключения темы).
- Селекторы интерфейса захардкожены; при редизайне Яндекса их нужно править вручную.

## Установка

Chrome: «Расширения» → «Режим разработчика» → «Загрузить распакованное» → папка `yandex-map-cleaner`.
