# Yandex Map Cleaner

Расширение для Chrome/Edge: минималистичный интерфейс на картах Яндекса, переключатель темы.

**Статус:** рабочая версия. Проверка обновлений отключена (CORS на github releases). Версия берётся из manifest.

## Установка

1. Скачайте или клонируйте репозиторий.
2. Откройте `chrome://extensions` (или `edge://extensions`).
3. Включите **«Режим разработчика»**.
4. Нажмите **«Загрузить распакованное расширение»** и выберите папку `yandex-map-cleaner`.

## Как пользоваться

1. Откройте [yandex.ru/maps](https://yandex.ru/maps).
2. Нажмите на иконку расширения в панели браузера.
3. Доступные кнопки:
   - **Скрыть / Показать UI** — убирает или возвращает интерфейс карты.
   - **2D / 3D** — переключает режим отображения.
   - **PPOI ветки / план** — переключает отображение точек.
   - **Светлая / Тёмная тема** — смена темы интерфейса.

Кнопка **«Обратная связь»** открывает форму для отзыва.
