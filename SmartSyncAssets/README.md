# Smart Sync Assets

Скрипт для Adobe After Effects. Копирует внешние исходники (файлы из загрузок, рабочего стола и т.д.) в папку `[Имя_проекта]_Assets` рядом с проектом и перепривязывает их в AE.

## Установка

1. Скачайте `SmartSyncAssets.jsx`
2. Поместите в папку скриптов AE: `Support Files/Scripts/ScriptUI Panels`
3. Откройте через **Window → Smart Sync Assets**

## Использование

1. Сохраните проект (File → Save)
2. Нажмите **Sync**
3. Файлы скопируются в `_Assets` и будут перепривязаны автоматически

**Опция «Удалить дубликаты»** — удаляет исходные файлы после успешного копирования (полный перенос).

## Поддерживается

- Одиночные файлы
- Секвенции кадров (переносит всю секвенцию в подпапку `Seq_[Имя]`)
- Защита от перезаписи (суффиксы `_1`, `_2` при совпадении имён)
